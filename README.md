
# Power Boost Official

A premium user dashboard and account website.

## Current Features

- Login and registration interface
- Forgot password interface
- Customer Service via Telegram
- User dashboard
- Coin balance display
- Add Fund and Withdraw interface
- Invite Friends and Earn Coins
- Transaction history
- Account settings

## Important

This frontend is currently a user interface. Real phone OTP verification, secure login, device/session management, referral verification, coin rewards, and transaction records require a secure backend and database.

## Setup

1. Upload the project files to this GitHub repository.
2. Enable GitHub Pages from Settings → Pages.
3. Select the `main` branch and `/ (root)` folder.
4. Save and open the generated website link.

## Support

Replace `YOUR_TELEGRAM_USERNAME` in the HTML files with your actual Telegram username.
